| 特性 | 一句话 | 详见 |
|------|--------|------|
| auto / decltype | 类型推导 | §C01.2、§C04.7 |
| 范围 for | `for (auto& e : v)` | §C02.2 |
| lambda | 就地匿名函数 | §C02.7 |
| 智能指针 | unique/shared/weak | §C06（全章） |
| 移动语义 && | 右值引用、移动构造 | §C07（全章） |
| nullptr | 真空指针（区别于 NULL） | §C03.2 |
| constexpr | 编译期常数 | §C01.3 |
| 初始化列表 + 统一初始化 | `int{5}`、`Vec3{1,2,3}` | §C01.2 |
| enum class | 强类型枚举 | §C01.6 |
| 线程库 | thread/mutex/atomic/future | §C09（全章） |
| 可变参数模板 | `template<class... Args>` | §C07.6 |
| = default / = delete | 显式要/禁默认行为 | §C05.2、第 06 题 |
| override / final | 重写核对/封条 | §C05.3、T2-28 |
| 委托构造 | 构造函数调另一个构造函数 | 例：`Box(int v):Box((double)v){}` |

## C++17（工程主力，本机完整支持）

| 特性 | 一句话 | 详见 |
|------|--------|------|
| 结构化绑定 | `auto [k, v] = pair;` | §C04.3 |
| if/switch 带初始化 | `if (auto n = f(); n>0)` | §C02.1 |
| inline 变量 | 头文件里定义全局变量 | T2-26 |
| std::optional | "可能有值可能没有" | 下文 |
| std::variant | 类型安全的 union | 下文 |
| std::string_view | 只读字符串视图（零拷贝） | 下文 |
| CTAD | `std::pair p(1, 2.0);` 免写模板参数 | ✓ |
| filesystem | 目录/文件操作 | §C12.3 |

optional/variant/string_view 三个小例子：

```cpp
#include <optional>
std::optional<int> find(int key) {          // 比"返回 -1 表示没找到"优雅
    if (key == 42) return 42;
    return std::nullopt;                     // "没有"
}
auto r = find(42);
if (r) printf("%d\n", *r);

#include <variant>
std::variant<int, std::string> v = "hi";    // 二者之一
if (auto* s = std::get_if<std::string>(&v)) printf("%s\n", s->c_str());

#include <string_view>
std::string_view sv = "hello world";        // 只读视图: 不拷贝、不拥有
std::string_view head = sv.substr(0, 5);    // 零拷贝取子串
```

## C++20（四大件，本机 GCC 11 部分支持）

| 特性 | 一句话 | 本机 |
|------|--------|------|
| **concepts** | 给模板参数"立规矩"，报错可读 | ✓（`std::integral` 等基础概念可用） |
| **ranges** | 管道式算法 `v \| filter \| transform` | ⚠ 部分（基础可用） |
| **coroutines** | 协程（co_await/co_yield） | ⚠ 仅裸机制，库支持差 |
| **modules** | 替代头文件 | ✗ 基本不可用 |

```cpp
// concepts: 模板参数必须满足条件, 违反时报错可读(替代古老的 SFINAE)
#include <concepts>
template <std::integral T>                 // 只许整数类型
T double_it(T x) { return x * 2; }
// double_it(3.14);                        // ✗ 报错直白: "约束不满足", 不再是千行模板错误

// ranges 管道(直观感受一下):
// auto evens = v | std::views::filter([](int x){ return x%2==0; })
//               | std::views::transform([](int x){ return x*x; });
```

【CUDA 相关】CUB/CUTLASS 3.x 大量使用 concepts 风格约束——看懂 `std::integral` 这类写法是读现代
GPU 库源码的门槛。

## C++23 / C++26（前瞻，本机 GCC 11 基本不支持，认识即可）

| 特性 | 版本 | 一句话 |
|------|------|--------|
| std::print / println | C++23 | `std::print("{}\n", x);` 替代 printf（Python 风格格式化） |
| std::expected<T,E> | C++23 | 类型安全的"成功或错误"返回值 |
| std::mdspan | C++23 | 多维数组视图（科学计算/HPC 关注） |
| deducing this | C++23 | 显式对象形参（简化 const/非 const 重复代码） |
| 静态反射 | C++26 已冻结 | 编译期类型自省（史诗级） |
| std::execution | C++26 已冻结 | 统一异步框架（Sender/Receiver） |

C++26 预计 2026 年内发布、特性已冻结（来源：[现代 C++ 教程 C++26 章](https://changkun.de/modern-cpp/zh-cn/12-cpp26/)、
[cppreference C++23/26](https://zh.cppreference.com/w/cpp/23)）。面试聊"你关注 C++ 新标准吗"——
答 C++23 的 expected/print + C++26 的反射即可，体现视野。
