# C07 移动语义与值类别 【进阶】

> C++11 最重要的性能特性。理解它 = 理解"为什么现代 C++ 代码不再拷贝大对象"。

## §C07.1 左值与右值

**作用**：值类别决定"这个表达式能不能被搬空"。

```cpp
int a = 42;
a;              // 左值: 有名字、有固定地址, 表达式结束后还在
42;             // 右值(纯右值): 临时的、马上就要消失的——"42"这个字面量
a + 1;          // 右值: 计算出来的临时结果
std::string("hi");   // 右值: 临时对象
```

判断法：**能对它取地址（&x 合法）→ 左值；临时的、即将消亡的 → 右值**。

## §C07.2 移动构造 vs 拷贝构造

**作用**：拷贝 = 复制全部内容（O(n)）；移动 = 把源对象的内部指针"抢"过来（O(1)）。

```cpp
std::string s1 = "hello world, a long string";
std::string s2 = s1;              // 拷贝构造: 真的复制一遍内容
std::string s3 = std::move(s1);   // 移动构造: s3 接管 s1 的内部指针, s1 变空壳
// 移动后 s1 处于"有效但未定义"状态: 能赋新值, 别假设它还有旧内容
```

### §C07.2.1 `&&` 语法本身 + 两个重载的分流实验（实测）

**`&&` = 右值引用类型**。它存在的意义不是"引用一个右值"这个动作本身，而是**给编译器一个分流标签**：同名重载同时提供 `const T&`（拷贝版）和 `T&&`（移动版）时，编译器按传入对象的"死活"自动选路。

```cpp
#include <cstdio>
#include <utility>
struct Vec3 {};
void who(const Vec3&) { printf("const Vec3& (拷贝版: 只能小心抄)\n"); }
void who(Vec3&&)      { printf("Vec3&&     (移动版: 可合法掏空)\n"); }
int main() {
    Vec3 a;
    who(a);            // ① 左值   → const Vec3&
    who(Vec3{});       // ② 临时值 → Vec3&&
    who(std::move(a)); // ③ 贴标签 → Vec3&&  (a 本身没死! 只是承诺不再用)
}
// 实测输出:
// ① const Vec3& (拷贝版...)
// ② Vec3&&     (移动版...)
// ③ Vec3&&     (移动版...)
```

**三个要点**（对照你 C05 的 Vec3 练习）：

1. **const T& 是万能备胎**：左右值都能绑。所以"没写移动构造时，临时对象也能构造"——走的是 const T& 的拷贝构造（你 main 里 `Vec3 v3 = v1 + v2;` 就是这么兜底的）。
2. **T&& 是专用快车道**：一旦存在，右值**优先**走它，性能自动升级（拷贝→偷指针）。
3. **std::move(a) 不杀 a**：它只是把 a 强转成右值（贴"临终"标签），a 还活着（处于"有效但未定义"状态），**不许再用它的内容**。

**人话版**：`&&` 是"**只接将死之人**"的专用通道。有这条通道，编译器才敢见人下菜碟——常驻居民（左值）走"慢慢抄"，临终患者（右值）走"器官捐献"（掏空指针）。

**记忆钩子**："const& 通吃，&& 优先接临时；move 只贴标签不动手。"

**自测**：① `who(std::move(a))` 之后再调 `who(a)` 走哪个版本？（还是 const Vec3&——a 作为变量仍是左值，标签只在那一次表达式有效）② 只删掉 `void who(const Vec3&)`，`who(a)` 还能编过吗？（不能——Vec3&& 绑不了左值；这正是"专用通道"的含义）

## §C07.3 移动构造函数怎么写

**作用**：自己的类要有"可搬"能力，就实现移动构造。

```cpp
class Buffer {
public:
    explicit Buffer(size_t n) : size_(n), data_(new char[n]) {}
    ~Buffer() { delete[] data_; }

    Buffer(const Buffer& o)                       // 拷贝: 深拷贝
        : size_(o.size_), data_(new char[o.size_]) { std::copy(o.data_, o.data_+o.size_, data_); }

    Buffer(Buffer&& o) noexcept                   // 移动: 抢指针! 必须标 noexcept
        : size_(o.size_), data_(o.data_) {        // (vector 扩容只敢用 noexcept 的移动)
        o.data_ = nullptr; o.size_ = 0;           // 源对象置空, 防止双重释放
    }
    Buffer& operator=(Buffer&& o) noexcept {      // 移动赋值: 同理
        if (this != &o) { delete[] data_; data_ = o.data_; size_ = o.size_;
                          o.data_ = nullptr; o.size_ = 0; }
        return *this;
    }
private:
    size_t size_; char* data_;
};
```

【坑】移动构造/移动赋值**必须标 noexcept**——否则 vector 扩容不敢用移动只敢用拷贝
（强异常安全要求，前置：T1-10）。

## §C07.4 std::move 的真相

**作用**：`std::move(x)` **什么都不搬**，只是一个到右值引用的强转 `static_cast<T&&>(x)`——
给编译器一个"允许掠夺"的标记。真正干活的是随后的移动构造/移动赋值。

```cpp
std::vector<int> v(1000000);
auto w = std::move(v);      // v 的百万元素"易主"给 w, 没有任何元素被复制
printf("%zu\n", v.size());  // 0 (变空壳)
```

【前置：T1-09】const 对象 move 静默退化成拷贝；返回局部变量**别写** return std::move（T2-18 RVO）。

## §C07.5 移动语义的工程价值

1. **容器与算法**：vector 存大对象时，元素可移动 = 扩容/排序快几倍；
2. **所有权转移**：`unique_ptr` 全靠移动语义（禁拷贝、送移动，前置：C06.2）；
3. **生产者-消费者**：队列里传大 buffer 用 move，避免整块 memcpy；
4. **CUDA 语境**：host 端预填充一个大 vector 后 `std::move` 交给管理类，避免 G 级数据二次拷贝
   （X05 的 mini 张量类会实际用到）。

## §C07.6 完美转发 std::forward（进阶）

**作用**：模板函数里"原封不动地把参数转给下一层"——原来是右值就保持右值。

```cpp
template <class... Args>
auto make(Args&&... args) {          // T&& 在模板推导中 = 万能引用
    return Widget(std::forward<Args>(args)...);   // 保真转发: 左值仍左值, 右值仍右值
}
```

【前置：T3-36 引用折叠规则】这就是 `emplace_back` 能就地构造的机制（T1-12）。
