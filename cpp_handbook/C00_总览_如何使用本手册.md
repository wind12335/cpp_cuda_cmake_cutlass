# C++ 参考手册 · 总览与使用说明

> 这是写给"有 CUDA 基础、C++ 需要从入门补到进阶"的手册。
> 与 `cpp_interview_notes/`（面试问答体）互补：**那边是题，这边是教科书**。

## 使用约定（三套符号，全书统一）

1. **章节编号**：每篇文档一个编号（C01、C02……），知识点按 `§C01.3` 这样引用。
2. **前置标注**：每个知识点开头如果有 `【前置：C03 §2 指针】`，表示"不理解前面的内容
   就先回去看"——学习时务必按依赖顺序，跳着看容易懵。
3. **标注体系**：
   - 【基础】入门必会；【核心】写工程天天用；【进阶】面试+深入用；【CUDA 相关】写 CUDA host 代码会碰到。

## 章节地图与依赖关系

```
C01 变量类型与运算符 ──┬→ C02 控制流与函数 ──┬→ C03 指针引用与内存 ──┬→ C05 类与对象 ──→ C07 移动语义
C01 ──────────────────┴→ C04 容器与算法 ────┤                        ├→ C06 智能指针与RAII
                                           └→ C08 模板与泛型 ←─────┤
C02 + C03 ──────────────────────→ C09 并发编程 ←──────────────────┘
C04 + C01 ──────────────────────→ C10 字符串流与文件IO
全部 ──────────────────────────→ C11 现代C++特性速查 / C12 工具库
```

**推荐学习顺序**：C01→C02→C03→C04（打地基）→ C05→C06（面向对象与现代内存管理）
→ C07→C08（进阶机制）→ C09（并发，写 CUDA host 必备）→ C10~C12（按需查阅）。

## 编译与运行约定（本机已验证）

```bash
g++ -std=c++17 -O2 -pthread xxx.cpp -o out && ./out   # 手册全部代码用这条能编译
```
- 本机 GCC 11.4：完整支持 C++17，支持大部分 C++20；C++23 需要 GCC 13/14（速查篇会标注"本机可/不可编译"）。
- `labs/` 目录下每个章节配一个**可编译运行的实验文件**，全部验证过。

## 权威资料（背书）
