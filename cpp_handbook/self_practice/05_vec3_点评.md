# 05_vec3.cpp 点评（针对你当前的版本）

## 1. 你的疑问：`new char[other._length]` 加 `*` 为什么报错？

**你写的 `new char[other._length]` 是对的**，加 `*` 反而错。原因：

- `_length` 的类型是 `int`（见 private 区）——**普通数字，不是指针**
- `new char[n]` 里的 `n` 要的是"**元素个数**"（一个数字），直接传即可
- `*`（解引用运算符）**只能用在指针上**。对 int 用 `*`，编译器报：

```
error: invalid type argument of unary '*'
```

**口诀**：看到 `*`，先问自己"**这是指针吗？**"（C03 指针篇的老规矩）

> 顺带：手册 C05 里那个 `*o.len_` 是**我写错的**（`len_` 成员根本不存在，`*` 也是错的），
> 已在 C05 发勘误并重写完整版。你是被错例子带偏的，不是你的问题。感谢抓 bug。

## 2. 你的拷贝构造：正确 ✓

- `_data(other._data)` / `_name(other._name)`：vector/string 成员**自动深拷贝**（它们自带全套）
- `_buffer(new char[other._length])`：裸指针成员**必须自己 new 新块**——你做对了。
  若写 `_buffer(other._buffer)` 就是浅拷贝：两个对象共用一块内存 → 析构时 delete 两次 → 崩。

## 3. 你的移动赋值：骨架全对，三个小点

✓ 做对的：`if (this != &other)` 防自移动、偷 `_buffer`、`other._buffer = nullptr` 置空源头、
`noexcept`、`return *this`——五要素齐了。

⚠️ 要改的：

1. **注释笔误**：`//拷贝赋值` → 参数是 `Vec3&&`（右值引用），这是**移动**赋值。
   （拷贝赋值的参数是 `const Vec3&`，你还没写——见第 5 节）
2. **偷之前先删自己的旧 buffer**：现在 `_buffer = other._buffer` 直接覆盖。本例里 `v4`
   是默认构造（`_buffer = nullptr`）侥幸不漏；但若 v4 之前 own 过内存，旧块就丢了（**泄漏**）。
   正确顺序：
   ```cpp
   if (this != &other) {
       delete[] _buffer;              // ← 先释放自己的旧家当
       _buffer = other._buffer;       //   再偷
       other._buffer = nullptr;       //   再置空源头
       ...
   }
   ```
3. `std::move` 的家在 **`<utility>`**，顶部补一行 `#include <utility>`（现在靠
   `<vector>`/`<string>` 传递包含碰巧编过，不可靠）。

## 4. main 里那行注释——你蒙对了，但原因很微妙

```cpp
Vec3 v3 = v1 + v2;   // 使用拷贝构造函数   ← 现在确实走拷贝构造, 但...
```

`operator+` 返回的是**临时对象**（右值）。用右值构造新对象时，编译器**优先找移动构造**；
但你还没写移动构造，所以**退而求其次用了拷贝构造**——注释现在是对的。

**微妙之处**：等你把第 5 节练习 ②（移动构造）补上，这行会**悄悄变成走移动构造**，一行代码
不改、行为自动升级。这就是为什么"五件套"要配齐——缺一件，性能就在暗处退化。

## 5. Rule of Five：你还差两件（练习）

已有：析构 ✓、拷贝构造 ✓、移动赋值 ✓。还缺：

**① 拷贝赋值**（参数 `const Vec3&`，和拷贝构造是两回事：一个是"出生时照着造"，
一个是"已存在的对象被别人覆盖"）：

```cpp
Vec3& operator=(const Vec3& other) {       // 拷贝赋值 五步版
    if (this != &other) {                  // 1 防自赋值 (v = v)
        char* fresh = new char[other._length];  // 2 先开新块(此时抛异常, 旧的还完好)
        std::memcpy(fresh, other._buffer, other._length);  // 3 拷内容
        delete[] _buffer;                  // 4 新的到手才删旧的
        _buffer = fresh;                   // 5 接管
        _x = other._x; _y = other._y; _z = other._z;
        _data = other._data; _name = other._name; _length = other._length;
    }
    return *this;                          // 返回自己, 支持 v1 = v2 = v3
}
```

**② 移动构造**（"出生版"的偷——在初始化列表里偷，不进函数体）：

```cpp
Vec3(Vec3&& other) noexcept                // 移动构造: 和你的移动赋值对照着看
    : _x(other._x), _y(other._y), _z(other._z),
      _data(std::move(other._data)),
      _name(std::move(other._name)),
      _length(other._length),
      _buffer(other._buffer) {             // 偷
    other._buffer = nullptr;               // 置空源头
}
```

补完这两件，你的 Vec3 就是教科书级 Rule of Five。补完后重跑 main，
观察 `Vec3 v3 = v1 + v2;` 是否如第 4 节所说悄悄换成了移动。
