# K05 常用命令、变量速查与排错 【随时查】

## 常用命令（按使用频率）

| 命令 | 作用 | 例子 |
|------|------|------|
| `cmake_minimum_required` | 版本声明（永远第一行） | `cmake_minimum_required(VERSION 3.18)` |
| `project` | 项目名+语言 | `project(x LANGUAGES CXX CUDA)` |
| `add_executable` | 声明可执行文件 | `add_executable(app main.cpp)` |
| `add_library` | 库（STATIC/SHARED/INTERFACE） | `add_library(k STATIC a.cu)` |
| `target_link_libraries` | 链接（带传递性） | `target_link_libraries(app PRIVATE k CUDA::cudart)` |
| `target_include_directories` | 头文件路径 | PUBLIC/PRIVATE 决定传递（前置 K03.2） |
| `target_compile_options` | 编译选项 | 配合生成器表达式 |
| `target_compile_definitions` | 注入宏 | `PRIVATE USE_FP16` ↔ 代码 `#ifdef` |
| `set` / `option` | 变量 / 开关 | 前置 K02 |
| `find_package` | 找外部库 | `find_package(CUDAToolkit REQUIRED)` |
| `add_subdirectory` | 进入子目录 | 多目录工程 |
| `enable_testing` + `add_test` | 测试 | 配合 ctest（前置 K04.4） |
| `message` | 打印调试 | `message(STATUS "arch=${CMAKE_CUDA_ARCHITECTURES}")` |

## 关键变量

| 变量 | 含义 |
|------|------|
| `CMAKE_BUILD_TYPE` | Debug/Release（**默认空=无优化，测性能必设 Release**） |
| `CMAKE_CUDA_ARCHITECTURES` | 86/89/90…（不设=编多架构，慢） |
| `CMAKE_CXX_STANDARD` | C++ 标准版本 |
| `PROJECT_SOURCE_DIR` | 项目根目录（拼路径） |
| `CUDAToolkit_ROOT` | CUDA 安装位置（多版本切换） |

## 生成器表达式（"条件编译选项"）

```cmake
$<$<COMPILE_LANGUAGE:CUDA>:-O3>     # 只对 CUDA 文件生效
$<$<CONFIG:Debug>:-g>               # 只在 Debug 配置生效
```

## 排错速查

| 症状 | 原因/解法 |
|------|----------|
| `cuda_runtime.h: No such file` | 纯 .cpp 用了 CUDA API → `find_package(CUDAToolkit)` + 链 `CUDA::cudart` |
| benchmark 数字虚低 | 忘了 `-DCMAKE_BUILD_TYPE=Release`（无优化编译） |
| `.cu` 不被编译 | project 忘了 `LANGUAGES CUDA` |
| 配置错误但被吞掉 | kernel launch 配置错误要靠 CUDA_CHECK（前置：X02） |
| 改了 .h 不重编 | 老式 include_directories 的依赖缺失 → 改用 target 方式 |
| 生成物污染源码 | in-source 构建了 → 删 `CMakeCache.txt CMakeFiles/`，以后用 `-B build` |
| `-arch` 相关怪错 | 架构号写错（4060=89 不是 80/86）；或 nvcc 太老不支持新架构 |
