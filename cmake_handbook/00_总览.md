## 三条总原则（先背）

1. **永远 out-of-source 构建**：`cmake -B build`，生成物全进 build/，删掉 build/ = 干净重来；
2. **现代 CMake 围绕 target**：一切设置（include/链接/宏）都"挂"在目标上，别用全局目录命令；
3. **必须显式设 `CMAKE_BUILD_TYPE`**——默认空 = 无优化，你的 benchmark 会测到假性能。

## 本机环境

cmake 3.22 + GCC 11.4 + nvcc 12.8（4060, sm_89）。常用命令：

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release     # 配置
cmake --build build -j8                       # 编译
ctest --test-dir build                        # 跑测试(有 add_test 时)
```
