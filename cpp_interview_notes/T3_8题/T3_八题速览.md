# T3 八题速览（面试前一晚扫一眼，每题 30 秒口径）

## 31 菱形继承与虚继承
B、C 都继承 A，D 继承 B、C → D 里有两份 A（两套成员、路径二义性）。
`class B : virtual public A` 让 A 在 D 中**只有一份**，由"虚基类指针/表"定位共享子对象。
代价：访问 A 成员多一次间接、构造顺序由"最终派生类直接初始化虚基类"接管。
追问：为什么虚基类由最派生类初始化？因为只有它知道整棵树的构造全貌，避免 B/C 各初始化一次 A。

## 32 模板为什么放头文件
模板是**实例化蓝图**：编译到具体 T 时必须有完整定义在场，才能生成代码。
定义放 .cpp → 其他 TU 实例化时看不到定义 → 链接期 undefined reference。
解法：① 定义全放头文件（主流）；② .cpp 里对用到的类型**显式实例化**（`template struct Foo<int>;`，
缺点是要枚举类型、别人加新类型编译不过）。
追问：为什么 .cpp 里的模板编译器不报错？——因为当前 TU 可能没人实例化它，语法检查通过就放过了。

## 33 this 指针本质
成员函数的**隐藏第一个参数**（`T* const this`），调用时由编译器传入对象地址；
`x.f()` 本质是 `f(&x)`。static 成员函数没有 this（不依赖实例），所以静态函数里不能访问非静态成员。
用途：`return *this` 支持链式调用（builder 模式）；防自赋值 `if (this == &o)`（联动 17 题）。
追问：this 是空指针时调成员函数？解引用成员必崩，但"不碰成员的成员函数"历史上能跑——标准未定义行为，别依赖。

## 34 friend
friend 函数/类可以访问本类 private/protected。
三个正当用途：① `operator<<` 重载（流对象在左，写不成成员函数）；② 紧耦合的成对类（容器和它的迭代器）；③ 单元测试访问私有状态。
注意：friend 是**单向、不传递、不继承**的（A 的朋友的朋友不是你的朋友）。
追问：friend 破坏封装吗？——它反而常常是"把接口写对"的工具：有些函数逻辑上属于类接口，只是语法上不能是成员。

## 35 decltype / auto 规则
`auto` 按值推导：**丢引用、丢顶层 const**（`const int& r = x; auto a = r;` → a 是 int）。
`auto&`/`const auto&` 保留引用性；`decltype(expr)` 得到表达式**声明类型**（保留引用和 const）；
`decltype(var)` 得到变量声明类型；`decltype((var))` 多一层括号变 `T&`（经典刁题）。
C++14 的 `decltype(auto)` 用于"返回类型完全跟随表达式"（想保留引用的返回）。
追问：什么时候必须 decltype？——写泛型转发代码时类型由参数表达式决定，auto 表达不了。

## 36 完美转发 std::forward
模板里的 `T&&` 不是右值引用，是**万能引用**：传左值推导成 `T&`，传右值推导成 `T&&`（引用折叠规则）。
但形参本身是具名变量、是左值——往里传会丢掉右值性。
`std::forward<T>(t)` 按 T 的推导结果**还原值类别**：原来是右值就还原成右值。
这正是 emplace_back 能把构造参数原封不动转发给 T 的构造函数的机制。
记忆：**move 是无条件转右值，forward 是有条件还原**；转发引用必须长成 `T&&` 且 T 是被推导的模板参数。

## 37 函数指针 vs std::function
函数指针：类型是"签名"，只能指向普通函数/无捕获 lambda，裸指针 8 字节，调用是间接跳转。
`std::function<签名>`：**类型擦除**的万能可调用体——函数、lambda（含捕获）、仿函数、成员函数绑定都能装；
代价是堆上可能存闭包 + 一次间接调用（通常妨碍内联），sizeof 一般 32 字节。
选择：回调接口稳定、性能敏感 → 模板参数或函数指针；需要"能装任何可调用物"的成员/容器 → std::function。
追问：std::function 为空调用会怎样？抛 std::bad_function_call——调用前判 `operator bool`。

## 38 C++11 常用的十个新特性（30 秒报菜名）
① auto/decltype 类型推导；② 范围 for；③ lambda 闭包；④ 智能指针三件套（unique/shared/weak）；
⑤ 移动语义 && 右值引用；⑥ nullptr（终结 NULL 的整型二义性）；⑦ constexpr 编译期计算；
⑧ 初始化列表 + 统一初始化语法；⑨ 线程库（thread/mutex/atomic/condition_variable）——**C++ 第一次有标准并发**；
⑩ 可变参数模板（tuple、make_shared、emplace 的地基）。
加分补充：enum class（强类型枚举）、static_assert、override/final、委派构造。
口径示例："我工程里用得最多的是智能指针+移动语义管资源、lambda+线程库做并发、auto 减少样板。"
