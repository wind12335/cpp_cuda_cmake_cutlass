# G06 流与事件与异步 【核心，你科研的主场】

> "重叠计算与通信"的微观基础——你的 overlap 论文就是本章在系统级的放大。

## §G06.1 为什么默认的写法是串行的

**作用**：理解"谁在等谁"。

```cpp
cudaMemcpy(d, h, bytes, H2D);      // ① CPU 发出并【阻塞等待】搬完
kernel<<<g, b>>>(d);               // ② kernel 启动(异步), 但必须等①的数据
cudaMemcpy(h, d, bytes, D2H);      // ③ 阻塞等待 kernel 完成+搬回
```

三步串行：GPU 搬运时计算单元闲着，计算时搬运引擎闲着。**流（stream）就是打破这个的工具**。

## §G06.2 流：GPU 上的任务队列

**作用**：同一流内严格按序，不同流之间可以并发。

```cpp
cudaStream_t s1, s2;
cudaStreamCreate(&s1);
cudaStreamCreate(&s2);

cudaMemcpyAsync(dst, src, bytes, cudaMemcpyHostToDevice, s1);  // 异步版: 指定流
kernel<<<grid, block, 0, s2>>>(...);                            // kernel 的第 4 参数 = 流
cudaMemcpyAsync(h, d, bytes, cudaMemcpyDeviceToHost, s2);

cudaStreamSynchronize(s1);      // 只等这个流
cudaStreamDestroy(s1);
```

【坑】kernel 默认的 legacy stream 和所有流**互斥**——只要还用默认流，多流就没意义。
【坑】`cudaMemcpyAsync` 配 pageable host 内存仍是同步行为——**必须配 pinned**（G04.4）。

## §G06.3 事件：计时与跨流依赖

**作用**：在流里立"路标"，用于①精确计时 ②跨流等待。

```cpp
cudaEvent_t start, stop;
cudaEventCreate(&start); cudaEventCreate(&stop);
cudaEventRecord(start, stream);        // 在流里插一个起点
kernel<<<g, b, 0, stream>>>(...);
cudaEventRecord(stop, stream);         // 终点
cudaEventSynchronize(stop);            // 等到终点路标被触发
float ms; cudaEventElapsedTime(&ms, start, stop);   // GPU 时间线上的真实耗时

// 跨流依赖: s2 必须等 s1 里的 event 触发后才能继续
cudaStreamWaitEvent(s2, event);
```

【前置：T2-24】为什么不用 CPU 秒表：kernel 启动是异步的，CPU 计时测到的是"发射时间"。

## §G06.4 流水线重叠的标准模式

**作用**：把大数据切块，让"传输第 i+1 块"与"计算第 i 块"同时发生。

```
单流:   [H2D 全部][计算全部][D2H 全部]              ← 三段串行
双流:   s1: [H2D块0][计算块0][D2H块0]
        s2:      [H2D块1][计算块1][D2H块1]        ← 传输和计算咬合
```

```cpp
for (int i = 0; i < nChunks; ++i) {
    int s = i % 2;                                    // 两个流轮流
    cudaMemcpyAsync(d_buf + i*chunk, h_buf + i*chunk, chunkBytes, H2D, streams[s]);
    kernel<<<grid, block, 0, streams[s]>>>(d_buf + i*chunk);
    cudaMemcpyAsync(h_buf + i*chunk, d_buf + i*chunk, chunkBytes, D2H, streams[s]);
}
```

【你的论文】单块内的"传输/计算"重叠 → 系统级的"通信/计算"重叠（NCCL 流 + 计算流 + event 依赖）
是同一个模型在不同尺度的复现。

## §G06.5 同步工具速查

| API | 等什么 |
|-----|--------|
| `cudaDeviceSynchronize()` | 等**全部**流的所有任务（最重） |
| `cudaStreamSynchronize(s)` | 只等流 s |
| `cudaEventSynchronize(e)` | 只等到某个事件点 |
| `cudaStreamWaitEvent(s, e)` | 不等待，只让流 s 的后续任务依赖 e |
