# G05 共享内存规约与原子操作 【核心】

> 目标：把"100 万个数求和"写对、写快——规约是 CUDA 并行思维的最佳教材。

## §G05.1 问题：并行求和不能"人人加到一个变量上"

**作用**：理解为什么需要树形结构。

```cuda
// ✗ 错误示范: 所有线程同时执行 out[0] += v[i]
//   读→加→写三步交错, 结果取决于时序 (丢更新)
// ✓ 正确思路: 两两配对折叠 —— 一半线程把"对面"的数加到自己身上, 活跃线程减半
//   log2(N) 步完成, 这就是"树形规约"
```

## §G05.2 共享内存 + __syncthreads 的 block 规约

**作用**：标准两段式——block 内先各自归约，再跨 block 汇总。

```cuda
__global__ void blockSum(const float* in, float* out, int n) {
    __shared__ float smem[256];
    int tid = threadIdx.x;
    int i = blockIdx.x * blockDim.x + threadIdx.x;
    smem[tid] = (i < n) ? in[i] : 0.0f;      // ① 每线程搬一个数进 shared
    __syncthreads();                          //    等全体装完 (必须!)

    for (int s = blockDim.x / 2; s > 0; s >>= 1) {   // ② 树形折叠
        if (tid < s) smem[tid] += smem[tid + s];
        __syncthreads();                      //    每步同步
    }
    if (tid == 0) out[blockIdx.x] = smem[0];  // ③ 每 block 的和写出去
    // host 端再把 out 里的 gridSum 个数求和(或再启动一个 kernel)
}
```

【坑】`if (tid < s)` 的写法在后半程有 warp divergence + idle lanes——进阶版用 warp shuffle
（面试 T2-14）+ 交错寻址消分歧。**本节的朴素版是面试手写的及格线**。

## §G05.3 warp shuffle：最后 32 个数用寄存器交换

**作用**：`__shfl_down_sync` 让 warp 内线程直接互换寄存器——绕开 shared memory。

```cuda
__inline__ __device__ float warpReduce(float v) {
    for (int offset = 16; offset > 0; offset /= 2)         // 16,8,4,2,1 五步
        v += __shfl_down_sync(0xffffffff, v, offset);      // 拿"我+offset"线程的值加给自己
    return v;                                              // warp 内所有线程都持有总和
}
```

## §G05.4 atomicAdd：多 block 直接累加

**作用**：省掉"第二个 kernel 汇总"，代价是热点竞争 + 浮点顺序不定。

```cuda
__global__ void blockSumAtomic(const float* in, float* total, int n) {
    // ... block 内规约到 smem[0] (同 §G05.2) ...
    if (threadIdx.x == 0) atomicAdd(total, smem[0]);   // 每 block 一个代表, 原子累加到全局
}
// 注意: 结果正确但每次运行的浮点加法顺序不同 → 数值有细微差异(可接受的换)
```

【前置：C09.3 atomic 的 CPU 版语义；CUDA 版同理，高竞争要分桶】

## §G05.5 常用原子函数速查

| 函数 | 作用 |
|------|------|
| `atomicAdd(int*/unsigned*/float*/double*)` | 原子加（float 要 sm_60+，double 要 sm_60+ Pascal 后） |
| `atomicSub` / `atomicMax` / `atomicMin` | 原子减/取大/取小（整型） |
| `atomicCAS` | 比较并交换——所有原子操作的地基（前置：T2-22 CAS） |
| `atomicExch` | 交换 |
