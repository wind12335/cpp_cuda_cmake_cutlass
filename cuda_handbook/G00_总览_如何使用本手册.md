# CUDA 参考手册 · 总览与使用说明

> 配套 `cpp_handbook/`（C 系列）：CUDA host 代码就是 C++，**C 手册是本手册的语法地基**。
> 环境已验证：RTX 4060 Laptop（sm_89, 8GB, 24 SM）+ CUDA 12.8，所有代码可单卡运行。

## 使用约定

- 章节编号 G01~G09；知识点编号 §G01.1；**前置标注**同 cpp 手册（不懂就回看）。
- 跨手册引用：【C++ C03】= cpp_handbook 第 03 篇；【面试 T1-05】= cuda_interview_notes。
- 所有 lab 编译命令统一：`nvcc -std=c++17 -O2 -arch=sm_89 xxx.cu -o out && ./out`
  （`-arch=sm_89` 是 4060 的架构号；不加也能编但会按默认架构，性能可能不对）。

## 编译nvcc 常用 flag 速记

| flag | 作用 |
|------|------|
| `-arch=sm_89` | 按目标架构生成 SASS（4060） |
| `-O3` | host+device 都优化 |
| `-g --generate-line-info` | 带源码行信息（ncu 里看源码） |
| `-Xptxas -v` | 打印每个 kernel 的寄存器/共享内存用量 |
| `-G` | device 代码不优化（调试用，性能崩） |

## 环境排错速记

| 症状 | 原因/解法 |
|------|----------|
| `nvcc: command not found` | `export PATH=/usr/local/cuda/bin:$PATH` |
| WSL 里 ncu 报 ERR_NVGPUCTRPERM | Windows 控制面板开性能计数器权限（见 4060_可学清单.md） |
| kernel 莫名其妙没效果 | 忘了 `cudaDeviceSynchronize()` / 错误没检查 |
| out of memory | 8GB 上限：检查有没有泄漏（每循环 new 不 free） |
