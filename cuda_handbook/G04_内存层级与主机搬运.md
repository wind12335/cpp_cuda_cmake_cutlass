# G04 内存层级与主机搬运 【核心】

## §G04.1 显存里的四层金字塔

**作用**：记住"每层的容量/延迟/谁来管"，所有优化决策的依据。

| 层 | 作用域 | 容量(4060) | 访问延迟 | 谁管理 |
|----|--------|-----------|---------|--------|
| Register | 单线程 | ~255 个/线程 | ~1 cycle | 编译器自动 |
| Shared Memory | 单 block | ~48-100KB/SM | ~30 cycle | **你手动** `__shared__` |
| L2 | 全 GPU | 32MB | ~200 cycle | 硬件自动 |
| Global (显存) | 全 GPU | 8GB | ~400-600 cycle | cudaMalloc |

外加两根"数据高速公路"：PCIe（host↔device，~16-64GB/s）和 NVLink（卡↔卡，4060 没有）。
【前置：面试 G03 有延迟/容量的完整实测与速记】

## §G04.2 寄存器：编译器自动分配的极速仓库

**作用**：kernel 里声明的局部变量自动放寄存器；放不下会"溢出"（spill）到显存——性能悬崖。

```cuda
__global__ void k(float* out) {
    float acc = 0;              // acc 住在寄存器
    for (int i = 0; i < 64; ++i) acc += i * 0.5f;
    out[threadIdx.x] = acc;
}
```

查用量：`nvcc -Xptxas -v` 打印每个 kernel 的寄存器数。超过 255/线程就会 spill，
ncu 的 local memory 指标非零 = 有溢出。

## §G04.3 cudaMalloc / cudaMemcpy 家族

**作用**：显存的 malloc/free 和搬运 API（数据流的骨架）。

```cpp
float* d_ptr;
cudaMalloc(&d_ptr, bytes);                        // 分配显存
cudaMemcpy(d_ptr, h_ptr, bytes, cudaMemcpyHostToDevice);   // 上传
cudaMemcpy(h_ptr, d_ptr, bytes, cudaMemcpyDeviceToHost);   // 下载
cudaMemset(d_ptr, 0, bytes);                      // 清零
cudaFree(d_ptr);                                  // 释放

// 方向枚举: cudaMemcpyHostToDevice / DeviceToHost / DeviceToDevice / Default(自动判断)
```

【坑】cudaMalloc 分配的显存 **host 代码不能直接解引用**（那是另一台"机器"的地址），
访问只能靠 cudaMemcpy 或 kernel。
【前置：X01】这六个 API 用 C++ RAII 包起来后，泄漏不可能发生。

## §G04.4 pinned 内存：让搬运变快变异步

**作用**：普通（pageable）内存搬运要先中转；锁页内存让 DMA 直通——快 30-50%，且**真异步**。

```cpp
float* h_pin;
cudaMallocHost(&h_pin, bytes);          // host 端锁页分配
// ... cudaMemcpy / cudaMemcpyAsync 都能用它 ...
cudaFreeHost(h_pin);
```

【实测】本机 pageable ~8.8GB/s vs pinned ~13.3GB/s（cuda_interview_notes T1-08 实验）。
【坑】锁太多挤占主机物理内存——只给热路径缓冲。

## §G04.5 __shared__：block 的私有片上内存

**作用**：速度接近寄存器（~30 cycle），block 内所有线程共享——tiling 的舞台。

```cuda
__global__ void k(float* out) {
    __shared__ float tile[256];              // 静态声明 (编译期定大小)
    tile[threadIdx.x] = out[threadIdx.x];    // 从 global 装进来
    __syncthreads();                          // ★ 屏障: 等全体线程装完
    out[threadIdx.x] = tile[255 - threadIdx.x];   // 现在可以安全读别人的数据
}
// 动态大小版本: extern __shared__ float dyn[];  启动时第三参数给字节数 k<<<g,b,bytes>>>
```

【坑】`__syncthreads()` 必须所有线程都执行到（不能放在分叉里）——否则集体挂死（面试 G22）。
【坑】bank conflict：32 个 bank × 4B，同 bank 不同地址串行（T1-05，pad/swizzle 解决）。

## §G04.6 统一内存（UM）：方便但别在性能路径用

```cpp
float* p;
cudaMallocManaged(&p, bytes);   // CPU/GPU 都能直接解引用同一地址
// 内核按需在 CPU/GPU 之间迁移页面 —— 方便原型, 性能不可控
```
