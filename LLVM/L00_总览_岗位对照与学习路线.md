# L00 总览：岗位对照与学习路线

**【前置标注】** 无，这是第一篇。

**【记忆钩子】** LLVM 是"一统编译器江湖的中间语言"，MLIR 是"可插拔方言的乐高积木"，Linalg 是"声明式算子库"，Triton 是"Python 写 GPU 内核"。你的岗位 JD 就是这四个词。

**【人话版】** 你以前学的 CUDA 是"怎么在 GPU 上算得快"；编译器岗研究的是"怎么让机器自动生成算得快的代码"。你已经会手写 mma、CUTLASS、优化 reduce——这些是编译器**要生成出来的目标**。现在学的是生成器的原理。方向不亏，反而互补。

---

## 一、你投的岗位到底要什么（JD 逐条翻译）

杭州先进编译科技《编译器研发工程师》JD 里的硬性项，逐条翻译成人话：

| JD 原文 | 人话 | 你现有的底子 | 缺什么 |
|---|---|---|---|
| Triton 编译器优化 | Triton 的 Python 代码怎么变成 GPU 上跑的机器码 | 会写 Triton 算子（LeetCUDA） | 只会"用"，不懂"怎么编译" |
| MLIR + Linalg 框架 | AI 编译器的中间表示和算子库 | 无 | **本手册主线** |
| 算子融合 | 把多个小 kernel 合成一个大 kernel 减少访存 | 懂为什么要融合（CUTLASS epilogue 就是手工融合） | 懂编译器怎么自动做 |
| 自动调优/代码生成 | 自动搜索最优 tile/block 配置 | 懂性能模型（roofline/occupancy） | 懂搜索空间怎么建 |
| LLVM/TVM/XLA/TorchInductor | 主流编译栈都知道 | 无 | L07 全景篇 |

结论：**你不是零基础，你是"知道目的地、没见过路线图"**。编译器岗面试官最爱考的就是"手工优化过的人转过来懂不懂自动化的边界"。

## 二、编译器在你的知识版图里的位置

```
你已掌握（能算）                本手册要补（能编）
─────────────────              ─────────────────
CUDA 执行模型                  LLVM：一统江湖的编译器基础设施
CUTLASS 模板元编程              MLIR：多层中间表示 + 方言机制
手动 epilogue 融合     ←——————→  Linalg：声明式算子 + 自动 lowering
LeetCUDA Triton 算子            Triton 编译栈（Python→PTX 全链路）
ncu/nsys 调优                   自动调优（autotune 搜索空间）
```

两边讲的是同一件事：左边是"答案"，右边是"出答案的机器"。

## 三、知乎高赞回答的路线（本手册的课程设计依据）

问题：《怎样去学习 mlir 这套框架？》(zhihu.com/question/435109274)

BobHuang（商汤 OpenDILab，编译器方向）高赞回答核心：

1. **方法论：抄写 Pass → 改写 Pass → 自制 Pass**
   （学编译器 = 学写 Pass，就像学 CUDA = 学写 kernel）
2. 官方文档 Toy Tutorial 是最好的入门（llvm-project 里的 `mlir/examples/toy/`，Ch1~Ch7，已帮你 clone 好）
3. 入门源码推荐 `mlir/test/lib/IR/TestPrintDefUse.cpp`、`TestPrintNesting.cpp`（L04 的 Pass 就是它的简化版）
4. 中文进阶仓库：**buddy-mlir**（北航赵 Eq 组出品，已帮你 clone 到本文件夹）

本手册 L01-L07 就是照这条路线铺的：L04 对应"抄写"，L05 对应"改写"，L06 之后进入 Linalg，之后自己啃 toy Ch1~Ch7（手册里有导读）。

## 四、学习时间预算（按你"白天论文、晚上 2 小时"的节奏）

| 阶段 | 内容 | 预计 |
|---|---|---|
| 第 1 晚 | L01 + L02 + L03（跑通 mlir-opt，建立概念） | 2h |
| 第 2 晚 | L04（抄写 Pass，编译运行 30min + 啃代码 1.5h） | 2h |
| 第 3 晚 | L05（改写 Pass，动手改规则做自测题） | 2h |
| 第 4-5 晚 | L06（Linalg，重点章，实验多） | 4h |
| 第 6 晚 | L07（生态全景 + 面试自测） | 2h |
| 之后 | toy 教程 Ch2/Ch3 精读（方言定义），面试前 Ch4~Ch7 扫读 | 长线 |

到 L07 学完，面试里"你了解 MLIR 吗"这个问题你就能从 Operation 讲到 Linalg 再串到 Triton——超过绝大多数同届竞争者。

## 五、三个仓库怎么用

| 仓库 | 在哪 | 怎么用 |
|---|---|---|
| llvm-project | `llvm-project/` | 只读。重点：`mlir/examples/toy/`（教程）、`mlir/test/lib/IR/`（入门 Pass 原型）、`mlir/include/mlir/`（当字典查 API） |
| buddy-mlir | `buddy-mlir/` | 只读。中文注释多的进阶教材，学完 L05 后看它的 `examples/` |
| 本手册 | 根目录 md + `labs/` | 动手做实验的唯一场所 |

⚠️ 不要试图在本机编译 llvm-project 或 buddy-mlir（内存 7.6G 不够，会 OOM 或跑一晚上）。看代码用眼睛，写代码用 apt 装的 MLIR 15 头文件和库。
