# C++×CUDA 结合部 · 总览

> 前两本手册的交汇点：**host 端的 CUDA 代码就是 C++ 工程**。这里的每一个技术
> （RAII、移动语义、模板、多线程）都会在"管理显存、包装 kernel、搭建框架"时用到。

## 前置要求

- 【C++ C03 指针与内存】【C06 智能指针与 RAII】【C07 移动语义】【C08 模板/functor】【C09 并发】
- 【CUDA G02 启动与错误检查】【G04 内存层级】【G06 流与事件】

## 章节地图

```
X01 显存管理 RAII 封装   ← C06 智能指针 + G04 cudaMalloc
X02 kernel 包装器与错误处理 ← G02 错误宏
X03 模板 kernel 与仿函数  ← C08 模板 + G03 elementwise (thrust 思想)
X04 host 多线程与多流    ← C09 并发 + G06 流
X05 端到端 mini 张量类   ← 全部汇总(毕业项目)
X06 pybind11 与 Torch 扩展导览 → 通向 LeetCUDA 的工程形态
```

## 编译约定

所有 lab 统一：`nvcc -std=c++17 -O2 -arch=sm_89 xxx.cu -o out && ./out`
（.cu 文件里 host 部分就是完整 C++——`std::vector`、lambda、类全都可用。）

## 学习收获自检（学完 X 系列你应该能）

1. 写一个"不可能泄漏显存"的矩阵类（离开作用域自动 cudaFree）；
2. 把 kernel 启动包装成类型安全、错误必查的函数；
3. 用模板 functor 写 elementwise kernel（理解 Thrust/CUB 的设计）；
4. 用两个 host 线程 + 两条流搭"预取-计算"流水线；
5. 读懂 LeetCUDA 里 `pybind` 目录的封装套路。
