## 通用编译命令（每个 lab 都用它）

```bash
CUTLASS=~/workspace/cuda_pybind_practice/third_party/cutlass
nvcc -std=c++17 -O3 -arch=sm_89 --expt-relaxed-constexpr \
    -I$CUTLASS/include -I$CUTLASS/tools/util/include \
    你的文件.cu -o out && ./out
```

| flag | 为什么 |
|------|--------|
| `-I$CUTLASS/include` | CUTLASS 全是**头文件库**，include 就能用 |
| `-I$CUTLASS/tools/util/include` | 官方例子用到的工具头（参考 tensor/host_tensor） |
| `--expt-relaxed-constexpr` | CUTLASS 内部需要在 device 里调 constexpr host 函数 |
| `-arch=sm_89` | 你的 4060 |

## ⚠️ 两个已实测的坑（本手册血泪记录）

1. **2.x 风格 `device::Gemm` 的 TensorOp 特化只到 `arch::Sm80`**——写 `Sm89` 会报
   `incomplete type DefaultGemmConfiguration`。解法：ArchTag 用 **Sm80**，其实现完整兼容
   sm_89 硬件（Ada 支持 Ampere 全部特性），直接跑、性能正常（03 章 17.7 TFLOPS 实测）。
2. 编译约 10 秒起步（重型模板）——正常，不是卡死。改一个模板参数 = 全量重编。
